# ShareOneList 隐私策略

**生效日期：2026 年 9 月 22 日 | 适用版本：v2.2.0 及后续版本**

本隐私策略说明 ShareOneList（以下简称"本应用"）如何处理您的数据。请在使用本应用前仔细阅读。安装或使用本应用，即表示您已理解并同意本策略。

- 开发者：ShareOneList Contributors
- 应用标识符：`com.shareonelist.app`
- 项目主页：https://github.com/ituff/ShareOneList

## 1. 数据处理总原则

ShareOneList 采用**本地优先**的设计：

- 本应用**没有开发者自己的服务器**，不含任何遥测、使用统计、崩溃上报或广告 SDK。
- 开发者**无法**访问您的 Microsoft 账户、云盘文件、聊天记录或任何配置数据。
- 您的数据只存储在**您自己的设备**上，或通过您本人的 Microsoft 账户存储在**您自己选择的微软云端**。
- 我们不出售、出租或以其他方式向任何第三方提供您的个人数据。

## 2. 存储在您设备上的数据

以下数据全部保存在本机的应用数据目录及系统凭据库中，仅用于本应用正常运行：

| 数据类别 | 内容 | 存储位置 |
|---|---|---|
| 账户信息 | 账户标识、显示名称、Drive 标识、云环境类型（国际版/世纪互联）、您设置的别名与图标 | 本地配置文件 `config.json` |
| 登录凭据 | Microsoft OAuth 访问令牌与刷新令牌 | 系统凭据库（Windows 凭据管理器 / macOS 钥匙串），不以明文写入文件 |
| 应用设置 | 主题、语言、窗口状态、下载目录、更新通道、备份目录等 | 本地配置文件 `config.json` |
| AI 供应商配置 | 供应商名称、API 地址、模型名称 | 本地配置文件 `llm.json` |
| AI API 密钥 | 您自行填写的模型供应商 API Key | 系统凭据库，**绝不**写入 JSON 配置文件 |
| 聊天历史与 AI 记忆 | 您与 AI 助手的对话记录，以及 AI 从对话中提取的长期记忆（如偏好、常用文件位置） | 本地 SQLite 数据库 `chat_history.db` |
| 目录索引（Drive Catalog） | 您浏览过的云盘目录的文件名、路径、标识等元数据索引，用于加速搜索 | 本地 SQLite 数据库 `catalog.db` |
| 下载的文件 | 您选择下载的文件内容 | 您指定的本机位置 |

上述数据均与您登录的账户绑定隔离，不与其他账户共享。

## 3. 数据何时会离开您的设备

本应用只在以下三种情况下发起网络通信，除此之外**没有任何其他数据外发**：

### 3.1 Microsoft 登录与 Graph API

- **登录**：浏览器跳转至微软登录页（国际版 `login.microsoftonline.com`，世纪互联版 `login.partner.microsoftonline.cn`），凭据由微软直接处理，本应用不经手您的密码。
- **文件操作**：浏览、搜索、上传、下载、分享等操作通过 Microsoft Graph API（国际版 `graph.microsoft.com`，世纪互联版 `microsoftgraph.chinacloudapi.cn`）使用您的 OAuth 令牌完成。这些数据由 Microsoft 依据[微软隐私声明](https://privacy.microsoft.com/privacystatement)处理。

### 3.2 AI 助手（您自行配置的模型供应商）

使用"问 AI"功能时，以下内容会发送到**您自己在应用内配置的 LLM 供应商端点**（如 OpenAI、Azure OpenAI、Anthropic 或其他兼容服务），并使用您自己的 API Key：

- 您的提问与对话上下文；
- 当 AI 需要引用某个云盘文件作答时，该文件经本机提取后的**文本摘录**；
- AI 记忆功能会将近期对话窗口发送给该模型，用于提取"长期记忆"，提取结果仅保存到您的本地数据库。

您向供应商发送的内容受该供应商自身的隐私政策约束，请自行查阅并谨慎选择。如果您不希望任何文件内容离开设备，请勿让 AI 引用文件，或暂不配置 AI 供应商。本应用的内置系统提示词由应用持有，您输入的 system 消息不会被发送。

### 3.3 更新检查

- 应用会访问 GitHub Releases 接口（`api.github.com`）检查新版本；
- 下载安装包时可能经由第三方加速镜像（`ghfast.top`、`gh-proxy.com`、`github.moeyy.xyz`）以改善中国大陆的下载体验；
- 该通信仅为常规 HTTP 请求，**不包含**您的账户、文件或任何身份数据。您也可以在设置中手动检查更新。

## 4. WebDAV 挂载

WebDAV 挂载功能在本机启动一个网关服务，用于将 OneDrive/SharePoint 目录映射到资源管理器或 Finder。该服务**仅监听本机回环地址 `127.0.0.1`**，并校验请求的 Host 头，不会暴露到局域网或互联网。

## 5. 备份与导出

您可以将设置与账户信息导出为本地文件，或自动备份到您在自己 OneDrive 中选定的文件夹（通过 Microsoft Graph 以您已登录的账户上传）。默认情况下备份**不包含任何凭据**。您可以选择性地加入敏感数据——登录凭据（refresh token）、AI 供应商 API Key、聊天记录、WebDAV 网关密码——一旦选择，这些部分会使用 AES-256-GCM 加密（密钥由您的备份密码派生）；密码本身绝不上传，恢复时必须输入。备份文件由您自行保管，请勿分享给不信任的对象。

## 6. 数据保留与删除

您对上述所有数据拥有完全控制权：

- **退出登录**：清除对应账户的 OAuth 令牌及本地会话。
- **应用内删除**：可随时删除聊天记录、AI 记忆和目录索引（相关 SQLite 数据库损坏时应用也会自动删除重建）。
- **完全清除**：卸载应用后，删除应用数据目录即可彻底清除全部本地数据：
  - Windows：`%APPDATA%\com.shareonelist.app`
  - macOS：`~/Library/Application Support/com.shareonelist.app`
- 发送给 LLM 供应商的数据，请依据该供应商的政策处理；存储于您 Microsoft 云端的文件，由您的微软账户控制。

## 7. 儿童隐私

本应用不面向 13 岁以下（欧盟境内为 16 岁以下）儿童，我们不会有意收集儿童的个人信息。

## 8. 您的权利

依据适用的法律（包括欧盟 GDPR、美国 CCPA、中国《个人信息保护法》等），您享有访问、更正、删除、携带及限制处理个人数据的权利。由于本应用的全部数据都存储在您自己的设备和您自己的微软账户中，您可以直接行使上述权利（参见第 6 节）。如仍有疑问，请通过第 10 节的渠道联系我们。

## 9. 国际数据传输

- 您选择配置的境外 LLM 供应商可能在其境外的服务器上处理和存储对话数据，具体以该供应商的政策为准。
- 微软云（国际版与世纪互联版）的数据处理分别遵循微软对应区域的隐私承诺。
